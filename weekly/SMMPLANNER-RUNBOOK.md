## Перед началом (проверки, при провале — остановиться и сообщить пользователю)
1. `git -C D:\Сlaude\yamalpark\site-public pull --rebase` (подтянуть сборку GitHub).
2. Дата контента: в `weekly/latest/post-glamping.txt` в первой строке стоит период «свободные даты на ДД–ДД месяца». Первый день периода должен быть сегодняшним (по Салехарду). Если нет — контент устарел, ничего не публиковать, сообщить.
3. Не дублировать: в SMMplanner (раздел «Посты») на сегодня уже могут стоять посты этой недели (текст начинается с «🏔 Глэмпинг · свободные даты», «🔥 Бани · …», «🍖 Гриль-дома…», «🎉 Чум, шатёр…»). Если такие уже есть для страницы «Ямал Парк» — не создавать повторно.
4. Если время слота уже прошло, поставить ближайшее свободное время не раньше чем через 15 минут, с шагом 2 часа между постами.
5. В Яндекс Браузере (Claude in Chrome, deviceId `a4a80c07-014e-4db2-8453-9e2db573a33c`, `select_browser`) должен быть выполнен вход в https://smmplanner.com. Если показывает форму входа — остановиться и попросить пользователя войти. Пароли никогда не вводить и не запрашивать.

## Как создать один пост в SMMplanner
Работать в новой вкладке, адрес https://smmplanner.com/home/new_posts/feed.
1. Нажать «Создать пост». Справа откроется панель «Добавить паблик».
2. В панели кликнуть по названию проекта «Ямал Парк» (раскрывается список), нажать «+» у трёх страниц: «Загородный комплекс «ЯМАЛ ПАРК» (ГЛЭМПИНГ)» (ВК), «Туристический комплекс "Ямал Парк"» (MAX), ««Ямал-Парк» - Загородный комплекс» (Telegram). Instagram («ТУРИСТИЧЕСКИЙ ЦЕНТР ОТДЫХА…») не добавлять. Проверить, что у трёх страниц вместо «+» стоит крестик/галочка. Нажать «Закрыть».
3. Кликнуть в поле «Что нового?» и напечатать текст действием `type` (form_input не работает — это не обычный input). Текст брать из файла категории дословно, ничего не переписывать.
4. Картинки: найти скрытый input type=file (`find` «hidden file input»), загрузить все слайды категории инструментом file_upload одним вызовом. Дождаться миниатюр.
5. Прокрутить окно вниз до блока «Время публикации». Для каждой из трёх страниц нажать на «Сейчас» справа от неё → значок карандаша в углу окна выбора → в поле ввести `ДД.ММ.ГГГГ ЧЧ:ММ` (например `23.11.2026 12:00`) → «OK». Убедиться, что у всех трёх страниц стоят дата и час.
6. Снять галочку «Разметка стилей текста» в «Настройках поста» (иначе ВК предупреждает про markdown).
7. Нажать «Запланировать» (НЕ «Опубликовать сейчас»). Появится «Публикация запланирована», счётчик всех постов вырастет на 3.
